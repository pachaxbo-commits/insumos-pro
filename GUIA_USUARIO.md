# GUIA_USUARIO

## Inicio de sesion

1. Abrir la URL del sistema.
2. Ingresar email y contrasena.
3. Si aparece acceso restringido, pedir revision del perfil o rol.

## Dashboard

El dashboard muestra ventas, cartera, stock critico, ultimas ventas y movimientos recientes.

## Productos

- Crear productos con categoria, unidad, stock minimo y precios.
- Editar datos base cuando sea necesario.
- Desactivar productos que ya no se usan.

## Inventario

- Registrar entradas, salidas, ajustes, mermas o devoluciones.
- El sistema bloquea salidas/mermas si dejan stock negativo.
- El historial muestra stock antes y despues.

## Compras

1. Crear compra en borrador.
2. Seleccionar proveedor y productos.
3. Confirmar compra para generar entradas automaticas de inventario.

## Ventas

1. Crear venta en borrador.
2. Seleccionar cliente y productos.
3. Confirmar venta para descontar inventario.
4. Si el pago es credito, se genera cuenta por cobrar.

## Finanzas

- Registrar cobros de clientes.
- Registrar pagos a proveedores.
- Registrar ingresos o gastos manuales.
- Revisar caja diaria.

## Reportes

- Filtrar por fecha, cliente, producto, proveedor o estado.
- Exportar CSV desde la pestana Exportaciones.

## Recomendacion diaria

Revisar dashboard, stock bajo, ventas pendientes, cuentas por cobrar y caja al cierre del dia.
