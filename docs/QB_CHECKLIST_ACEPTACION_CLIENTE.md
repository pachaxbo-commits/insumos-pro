# QB Insumos — aceptación del cliente

- [ ] Production abre en `https://qb-insumos.vercel.app`.
- [ ] Administrador e inventario ingresan con cuentas personales y ven solo lo permitido.
- [ ] Cliente registrado e invitado completan sus flujos sin acceso interno.
- [ ] Catálogo, fotografías, unidades, precios y productos por Bs están aprobados.
- [ ] Un pedido puede prepararse, guardarse, entregarse y convertirse en recibo sin duplicar stock.
- [ ] Hoja de mercado suma solicitudes repetidas, conserva unidades y descarga un Excel imprimible.
- [ ] Recibo acumulativo usa cantidades reales entregadas y permite precio, costo manual y utilidad administrativa.
- [ ] Recibo para cliente y nota sin precios ocultan costos, utilidad, factores y códigos internos.
- [ ] Cliente confirma si los productos repetidos se consolidan en una fila o se muestran por pedido.
- [ ] Un ingreso clasificado distribuye 100 % y no deja stock en el producto fuente.
- [ ] Recuperación de contraseña envía correo, cambia la clave y rechaza reutilizar el enlace.
- [ ] Inventario de apertura fue conciliado con fecha de corte y movimientos trazables.
- [ ] No quedan saldos negativos ni datos piloto ambiguos aprobados para eliminación.
- [ ] Control estricto permanece desactivado hasta la autorización final del responsable.
- [ ] Soporte, respaldo y responsables de salida están confirmados.
