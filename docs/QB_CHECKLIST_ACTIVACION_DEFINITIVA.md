# QB Insumos — checklist de activación definitiva

No activar control estricto ni ejecutar limpieza hasta completar las compuertas
aplicables y obtener autorización expresa.

- [ ] Usuarios reales creados.
- [ ] Cuentas demo identificadas por UUID y evidencia.
- [ ] SMTP probado.
- [ ] Recuperación probada, incluido token usado y vencido.
- [ ] Catálogo inicial revisado.
- [ ] Precios revisados y aprobados.
- [ ] Fotografías prioritarias cargadas.
- [ ] Unidades revisadas.
- [ ] Conversiones revisadas.
- [ ] Stock inicial cargado y conciliado.
- [ ] Negativos regularizados.
- [ ] Pedidos QA identificados inequívocamente.
- [ ] Limpieza autorizada por alcance exacto.
- [ ] Respaldo o reporte previo confirmado.
- [ ] Prueba por roles aprobada.
- [ ] Prueba PC y celular aprobada.
- [ ] Aceptación del cliente registrada.
- [ ] Control estricto activado conscientemente por administrador.
